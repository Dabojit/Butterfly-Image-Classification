📡 API Reference

Base URL: http://localhost:5000

GET /health
Check if server and model are ready.
curl http://localhost:5000/health
GET /info
Get model info, class list, and all endpoints.
curl http://localhost:5000/info
POST /predict?top_k=5
Predict species from an uploaded image file.
curl -X POST http://localhost:5000/predict \ -F "file=@butterfly.jpg" \ -G -d "top_k=5"
POST /predict_base64
Predict from a base64-encoded image (JSON body).
curl -X POST http://localhost:5000/predict_base64 \ -H "Content-Type: application/json" \ -d '{"image": "<base64_string>", "top_k": 5}'
POST /predict_batch?top_k=3
Predict multiple images in one request (max 20).
curl -X POST http://localhost:5000/predict_batch \ -F "files=@img1.jpg" \ -F "files=@img2.jpg"
POST /reload
Hot-reload the model from disk (no restart needed).
curl -X POST http://localhost:5000/reload
